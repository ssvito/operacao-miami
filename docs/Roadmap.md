# Roadmap

Parte de [Operação Miami](./Operacao%20Miami.md).

## Direção

- Mesma direção do ICE Breaker: aprendizado/portfólio, motor feito à mão em TypeScript + Canvas.
- Multiplataforma = PWA (manifest + service worker) + canvas responsivo + Pointer Events.

- [x] Scaffold - Vite/TS, game loop, canvas com escala inteira, manifest e service worker.
- [x] Decidir o núcleo: um minigame por fase, layout retrato.
- [ ] Shell de fases: cartão de título, troca de minigame, barra de exposição persistente.
- [ ] Fase 1 jogável (Gabinete): arrastar o personagem entre esconderijos, um repórter com cone de visão.
- [ ] Tela inicial com aviso de paródia.
