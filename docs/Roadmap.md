# Roadmap

Parte de [Operação Miami](./Operacao%20Miami.md).

## Direção

- Mesma direção do ICE Breaker: aprendizado/portfólio, motor feito à mão em TypeScript + Canvas.
- Multiplataforma = PWA (manifest + service worker) + canvas responsivo + Pointer Events.
